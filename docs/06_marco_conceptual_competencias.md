# Marco conceptual de competencias

El proyecto adopta una definicion amplia de competencia: combinacion de conocimientos, habilidades, criterios y capacidades de accion que permiten generar valor en una organizacion.

## Competencias analiticas

Capacidad para formular preguntas, explorar datos, identificar patrones, interpretar indicadores y distinguir evidencia relevante de ruido. Incluye pensamiento critico, estadistica aplicada y criterio para transformar datos en conclusiones.

## Competencias tecnicas

Capacidad para operar con datos mediante herramientas y lenguajes. Incluye SQL, Python, hojas de calculo, visualizacion, modelado de datos, automatizacion y documentacion tecnica. En este proyecto se consideran medios para producir valor, no fines autonomos.

## Competencias de negocio

Capacidad para comprender objetivos organizacionales, procesos, metricas, clientes, productos y restricciones del contexto. Permite conectar hallazgos analiticos con decisiones reales.

## Competencias comunicacionales

Capacidad para explicar resultados, construir narrativas, adaptar el mensaje a diferentes audiencias y facilitar conversaciones con stakeholders. Es clave cuando el analista actua como puente entre datos y decision.

## Competencias metodologicas

Capacidad para trabajar con orden, trazabilidad, criterios de calidad, priorizacion y reproducibilidad. Incluye documentar supuestos, validar fuentes y sostener procesos analiticos confiables.

## Relacion con la formacion academica

La formacion del analista deberia integrar tecnologia, estadistica, negocio y comunicacion. El valor profesional surge de la articulacion entre estas dimensiones, especialmente cuando el analista puede interpretar una necesidad organizacional y traducirla en una solucion basada en datos.

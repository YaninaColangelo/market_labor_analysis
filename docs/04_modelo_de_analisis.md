# Modelo de analisis

El modelo de analisis organiza cada oferta laboral en cinco dimensiones principales.

## 1. Necesidad organizacional

Representa el problema o aspiracion que la empresa busca resolver. Categorias iniciales:

- Seguimiento de indicadores y performance.
- Soporte a la toma de decisiones.
- Automatizacion y eficiencia operativa.
- Conocimiento de clientes, usuarios o mercado.
- Control de gestion y reporting ejecutivo.
- Mejora de procesos internos.
- Gobernanza, calidad y disponibilidad de datos.

## 2. Competencias del analista

Las competencias se interpretan como capacidades profesionales, no solo como conocimientos tecnicos.

- Analiticas: exploracion, interpretacion, pensamiento estadistico.
- Tecnicas: extraccion, transformacion, modelado y visualizacion.
- De negocio: comprension de procesos, metricas y objetivos.
- Comunicacionales: storytelling, presentacion, trabajo con stakeholders.
- Metodologicas: documentacion, criterio de priorizacion, calidad del dato.

## 3. Herramientas

Las herramientas se registran como instrumentos de trabajo. No definen por si solas el valor del rol, pero permiten observar la infraestructura analitica esperada.

Ejemplos: SQL, Python, Excel, Power BI, Tableau, Looker, dbt, Git, BigQuery.

## 4. Contexto de la oferta

Incluye pais, ciudad, industria, seniority, modalidad y tipo de empresa. Esta dimension permite comparar condiciones de demanda.

## 5. Relacion con la formacion

Se evalua si la oferta se vincula con contenidos academicos como estadistica, bases de datos, visualizacion, investigacion aplicada, administracion, economia, sistemas o comunicacion de resultados.

## Lectura integrada

El analisis cruza dimensiones para interpretar patrones. Por ejemplo:

- Reporting ejecutivo + Power BI + comunicacion con direccion = necesidad de visibilidad y control.
- SQL + calidad de datos + procesos internos = necesidad de confiabilidad operativa.
- Python + modelos predictivos + marketing = necesidad de anticipacion y segmentacion.
